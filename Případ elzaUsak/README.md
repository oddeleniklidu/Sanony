## Jak číst záznamy

Tabulky zachovávají výroky včetně původního jazyka, urážek a nepodložených obvinění. **Jsou to citované výroky z dodaných podkladů, nikoli zjištění nebo stanovisko Oddělení klidu.** Šanon jejich pravdivost neposuzuje a z jednotlivých komentářů nevyvozuje organizované jednání či osobní vazby.

Export popisuje komentáře jako poslední uloženou podobu včetně později nenalezených záznamů. XML označuje 59 komentářů stavem `active` a 3 stavem `missing`. Označení `missing` samo neprokazuje smazání ani to, kdo případné odstranění provedl. Čas poslední kontroly každého komentáře a úplná historie úprav nejsou součástí exportu. Zkrácené názvy videí nejsou jejich úplnými názvy.
