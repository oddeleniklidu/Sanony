## Web

[Otevřít web Šanony](https://oddeleniklidu.github.io/Sanony/)

Web publikuje GitHub Pages z kořene větve `main`. Úvodní stránky případů načítají obsah příslušného `README.md`; úpravy podkladů se tedy projeví i na webu po novém sestavení.

## Vydřin archiv

[Šablona nového šanonu a redakční pravidla](templates/README.md) vycházejí ze struktury šanonu Red Face. Šablony se na web nepublikují.

Společný vzhled se spravuje v `assets/archive.css`, `_layouts/default.html` a `_includes/entrance.html` obou repozitářů. Obsah šanonů zůstává v Markdownu. [Kam nahrát vizuál Vydry](docs/vizual-vydry.md).

Kontrola PR sestaví Jekyll, prověří místní odkazy a nabídne sestavený web jako artefakt `vydrin-archiv-preview`. Publikování na GitHub Pages nadále probíhá z větve `main`.

## Vizuální identita M1.2

Tmavé digitální rozhraní Oddělení klidu, zelený akcent, místně hostované fonty Inter a Barlow Condensed a Vydra v roli archiváře s kombinovaným tabletem a čtečkou (úprava dodané postavy na výslovné zadání uživatele). Změna se týká prezentace; obsah případů a zdrojová data se neupravují. [Vizuály a jejich nastavení](docs/vizual-vydry.md).
